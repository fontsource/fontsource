Monaspace Xenon is the slab serif member of Monaspace, a five-family type system created by GitHub Next and Lettermatic for displaying code. Its sturdy serif forms add a more structural voice to the system. The five families share metrics so they can be mixed while preserving the monospaced grid.

Its variable font spans weight, width, and slant. OpenType features include coding ligatures, character variants, and texture healing, which substitutes neighboring letterforms to produce a more even typographic texture without changing their fixed widths.
