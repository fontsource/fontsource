Monaspace Krypton is the mechanical sans member of Monaspace, a five-family type system created by GitHub Next and Lettermatic for displaying code. Its engineered voice emphasizes the system’s technical character. The five families share metrics so they can be mixed while preserving the monospaced grid.

Its variable font spans weight, width, and slant. OpenType features include coding ligatures, character variants, and texture healing, which substitutes neighboring letterforms to produce a more even typographic texture without changing their fixed widths.
